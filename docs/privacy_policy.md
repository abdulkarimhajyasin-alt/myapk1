# Maskan Privacy Policy Draft

Last updated: May 18, 2026

Maskan helps private housing groups track shared expenses and settlements.

## Information Stored

Maskan stores shared network data in Supabase so members can collaborate across
devices. This includes network names, member names, expenses, notes, currency
settings, notifications, avatar preferences, cycle/reset records, and session
metadata. Passwords are stored as hashes with salts. Raw passwords are not
stored.

## Notifications

Maskan may show local Android notifications for shared network activity while the app receives realtime updates. A future production push phase may add server-delivered push notifications.

## Data Sharing

Maskan does not sell personal data. Shared network data is visible to members of the same network.

## Data Retention

Supabase data remains in the configured project until deleted by the project
owner or through app flows.

## Contact

For privacy questions, contact Karamix Labs through the official website.
