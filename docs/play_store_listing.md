## English Short Description

Private shared housing expenses, settlements, and member activity.

## Arabic Short Description

تنظيم مصاريف السكن المشترك والتسويات بين الأعضاء بوضوح.

## English Full Description

Maskan is a private expense-sharing app for shared housing groups. Create a
cloud network, add members, record expenses, track who paid, review member
history, and generate clear settlements.

Features:

- Supabase cloud data shared across devices
- Arabic and English interface with RTL support
- Member accounts and avatar colors
- Expense notes and activity timeline
- Settlement summaries and PDF export
- Reset/new cycle approval flow
- Invite links and QR codes
- Realtime dashboard, notification, member, settlement, and cycle updates
- Android notifications while realtime updates are received

Maskan keeps the experience focused on small private groups and preserves
Karamix Labs support links in the app footer.
