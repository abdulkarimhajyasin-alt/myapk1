## English Short Description

Private shared housing expenses, settlements, and member activity.

تنظيم مصاريف السكن المشترك والتسويات بين الأعضاء بوضوح.

## English Full Description

Maskan is a private expense-sharing app for shared housing groups. Create a network, add members, record expenses, track who paid, review member history, and generate clear settlements.

Features:

- Local-first mode by default
- Optional Supabase cloud mode for shared devices
- Arabic and English interface with RTL support
- Member accounts and avatar colors
- Expense notes and activity timeline
- Settlement summaries and PDF export
- Reset/new cycle approval flow
- Invite links and QR codes
- Realtime dashboard refresh in cloud mode
- Local Android notifications while realtime updates are received

Maskan keeps the experience focused on small private groups and preserves Karamix Labs support links in the app footer.
